练习打字的同时记忆考公成语与实词释义（词和释义都需要手打）

React hook + TS 实现

## 开发环境
1. 安装[nodejs](https://nodejs.org/zh-cn/download/)，版本是 14 或以上
2. 安装依赖
   ```
        npm install
   ```
3. 安装完成后运行`npm run start`

## 直接使用（离线包）

不想每次开项目时，打一个离线包，之后双击 HTML 就能用，不需要 node 或本地服务：

```bash
npm run build:offline   # 产物在 offline/，相对路径 + hash 路由
```

打包完成后双击 `offline/index.html` 即可（推荐 Chrome / Edge）。练习记录存在浏览器的 localStorage 里，换浏览器或清理浏览器数据会丢失。


## 考公词库（打字内容）

打字内容已替换为考公相关词库（原 JS/CSS 代码词库已删除），数据统一放在 `src/data/kaogong/` 目录：

- `chengyu.ts`：考公行测高频成语 100 个（按近五年考频排序，释义含侧重点辨析）
- `shici.ts`：考公/行测高频实词辨析 913 个（按 456 组易混词整理，如 制定·制订、启用·起用）
- `content/`：**Word 导入目录**，把 `.docx` 词库文档放进去，运行下面命令即可自动生成自定义词库

```bash
npm run kaogong:word   # 解析 content/*.docx -> content/generated.ts
```

Word 内容格式（每行一个词条，支持：`词，释义`、`词：释义`、纯词行、一行多词用顿号分隔，行首自动编号会被忽略），详见 `src/data/kaogong/content/README.md`。

页面顶部词库标签可切换：必会成语 / 高频实词 / 自定义词库（Word 导入）/ 全部词库。点击「开始练习」后开始计时，每题需要依次打出「词 + 空格 + 释义」，打完自动进入下一题，错字以朱色标出。

- **计时器**：卷面顶部的计时是本次练习的真实用时；点「暂停」或按 `Esc` 可以暂停（暂停时不会继续计时），切到其他标签页也会自动暂停。
- **练习记录**：完成一遍（或中途重开）会把速度、正确率、进度、用时记到本机浏览器，点右上角「记录」查看最近 60 条，可一键清空。
- **手迹对照**：当前题下方会多一行「手迹」，逐字显示你实际打出来的内容，错字朱色标出；已完成的题只在有错字时保留手迹。
- **输入法**：隐藏输入框放在整行下方，输入法候选窗不会盖住正在打的那一行；当前行定位在卷面偏上位置，软键盘弹出时也不会顶掉内容。
- **跳过本题**：卡住时点页脚「跳过本题」，该题不计入本次统计；新题空输入按一次退格可回到上一题。
- **自适应**：桌面端卷面撑满窗口高度、内部滚动；窄屏自动隐藏竖排页边、统计改为两列，手机上也能正常打。

- **说明**：打字引擎已适配中文输入法（composing 期间不误换行），并修复了词库最后一行被丢弃的问题。
